# Анализ системы метрик приложения

**Задачи проекта:** Провести анализ юнит-экономики и рентабельности маркетинговых каналов подписочного сервиса для выявления причин стагнации выручки и разработки корректирующих мер.

**Описание проекта:** Проведён когортный анализ данных о пользователях и их платежах за первые 28 дней после привлечения. Рассчитаны ключевые метрики: Customer Acquisition Cost (CAC), Lifetime Value (LTV), Return on Investment (ROI) и конверсия в разрезе каналов привлечения. Выявлено, что основной маркетинговый бюджет направлен в неокупаемые каналы, в то время как единственный прибыльный канал недополучает финансирования. Определены периоды окупаемости для каждого канала и причины падения эффективности ранее успешных источников трафика. Подготовлены конкретные рекомендации по перераспределению бюджета и оптимизации стратегии привлечения.

# **Анализ юнит-экономики подписочного сервиса**

### **Задачи проекта**

- анализ юнит-экономики и рентабельности маркетинговых каналов
- выявление причин стагнации общей выручки
- разработка корректирующих мер по оптимизации маркетинга

### **Описание проекта**

Проведён когортный анализ пользователей и их платежей в течение первых 28 дней с момента привлечения. В рамках исследования рассчитаны и сравнены ключевые метрики эффективности по каждому каналу.

### **Ключевые метрики**

- **CAC (Customer Acquisition Cost):** стоимость привлечения клиента
- **LTV (Lifetime Value):** пожизненная ценность клиента
- **ROI (Return on Investment):** возврат на маркетинговые инвестиции
- **Конверсия** в подписку и платежи

### **Основные выводы**

**Выявлены структурные проблемы в распределении бюджета:**

- основные маркетинговые затраты направляются в **неокупаемые каналы**
- единственный **прибыльный канал** недополучает финансирования
- определены периоды окупаемости для каждого источника трафика
- установлены причины снижения эффективности ранее успешных каналов

### **Рекомендации**

1. перераспределить маркетинговый бюджет в пользу рентабельных каналов
2. оптимизировать стратегию привлечения с акцентом на unit-экономику
3. внедрить регулярный мониторинг окупаемости по каналам
4. разработать корректирующие меры для неэффективных источников трафика
